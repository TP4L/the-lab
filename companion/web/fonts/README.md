# THE LAB interface fonts

Self-hosted Google Fonts, distributed under the SIL Open Font License included next to each font.

- Archivo Black: broad wordmark, implementation equivalent for the BASAL reference.
- Anton: condensed headings, implementation equivalent for the BRUNCH reference.
- Manrope variable: readable interface and body text.

These are not the proprietary BASAL or BRUNCH font files. WOFF files were converted without changing outlines from the upstream TTFs using fontTools.

Sources: https://github.com/google/fonts/tree/main/ofl/archivoblack , https://github.com/google/fonts/tree/main/ofl/anton , https://github.com/google/fonts/tree/main/ofl/manrope .
